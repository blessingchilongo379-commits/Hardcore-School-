    SYSTEM DOCUMENTATION

    About Hardcore School

    Hardcore School is a learning and revision application designed to organise lessons, quizzes, revision, accessibility tools and learner support in one place.

    How to use the application
    Choose a grade, select a subject, then choose Learning or Quiz mode. In Quiz mode, answer the options before the timer ends. Use Read again when you want the current question repeated. Use 50/50 when available. At the end, review mistakes and use the revision reader. Voice controls, timing, accessibility, themes, sounds and other preferences are controlled from Settings.
    Accessibility & voice
    The browser's available speech voices are listed in Settings. Select a voice, test it, refresh the list when a phone/browser adds voices, and adjust speed, pitch and volume. The application cannot expose a voice that the browser or operating system does not provide.
